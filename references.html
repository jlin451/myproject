Standards Organizations

Several organizations contribute to the development and maintenance of HTTP standards and web technologies.

  • World Wide Web Consortium (W3C) - Develops and maintains web standards.
  • Internet Engineering Task Force (IETF) - Oversees many internet protocol standards, including HTTP specifications.
