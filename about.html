Project Overview

This website was created as part of a research project on Hypertext Transfer Protocol (HTTP) for IT 3203, and its role in the evolution of the web.

The website discusses HTTP fundamentals, the history of the protocol, key concepts used in web communication, and resources for additional learning.

Why I Chose This Topic

HTTP is one of the most important technologies used on the internet. Every website, web application, and API depends on HTTP to exchange information between clients and servers so fully understanding its role is essential as someone working within the industry.

Additionally, learning about HTTP provides a better understanding of how websites function in general and how modern web technologies continue to evolve.

Research Goals

  • Understand how HTTP works.
  • Explore the history of HTTP and the World Wide Web.
  • Learn about the different HTTP versions.
  • Understand web security through HTTPS.
  • Examine how HTTP supports modern applications and APIs.

Future Development

HTTP is only going to become faster overtime, making websites and apps extremely responsive. There will be a major focus on improving efficiency for mobile users, as well as working closely with AI tools. As technology advances, HTTP will keep being a key part of how we share and access digital info.
